# 🛍️ Perfume E-Commerce App (MERN Stack)

A full-stack e-commerce web application built with **React**, **Node.js**, **Express**, and **MongoDB**, allowing users to browse perfumes, add items to the cart, and securely sign up or log in.

## 🌐 Deployed Links

- 🧑‍💼 **Public Site**: [https://perfume-frontend-dusky.vercel.app/](https://perfume-frontend-dusky.vercel.app/)
- 🛠️ **Admin Dashboard**: [https://perfume-admin-seven.vercel.app/](https://perfume-admin-seven.vercel.app/)

## 🔧 Features

- 🔐 User Authentication (JWT-based)
- 🖼️ Product listing with image support
- 🛒 Add to Cart and Checkout functionality
- 🧑‍💼 Admin Dashboard for Business Owner
- 📱 Fully Responsive Frontend Design

## 🛠️ Tech Stack

- **Frontend**: JavaScript, React, TailwindCSS
- **Backend**: Node.js, Express
- **Storage**: MongoDB (Atlas) for data, Cloudinary for images
